# Banda-Clasificadora
Creación de un sistema de clasificación de objetos usando lector de NFC.

## Estructura

- `pruebas/` — pruebas de módulos individuales (servo, NFC, UART).
- `web/` — prototipo del panel web con simulador del ESP32. Ver [web/README.md](web/README.md).
- `docs/` — documentos de avance y [conexiones del hardware](docs/conexiones.md).
